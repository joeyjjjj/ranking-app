# IkonoiJoy Song Ranker

Pairwise song ranking for ＝LOVE / ≠ME / ≒JOY. Produces an exact top-20 order via gate-and-binary-insert comparisons.

## Requirements

- Node.js 18+
- npm

## Setup

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Other commands

| Command | Description |
| --- | --- |
| `npm run build` | Typecheck and production build to `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm run lint` | Run ESLint |
| `npm run deploy` | Build for GitHub Pages and publish `dist/` |
